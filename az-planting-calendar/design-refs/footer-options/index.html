Footer — three premium variations

All three remove the duplicated About (a section headed “ABOUT” containing a link named “About”) and the repeated Contact. Section labels now describe a group, never repeat a destination. Each column is a structurally different layout, not a recolour — pick a layout, or mix (“A’s source card, B’s columns”).

A — Utility bar

Lowest height. Two-up link grid, no section headers at all, source pinned as one card. Best if the footer should get out of the way.
