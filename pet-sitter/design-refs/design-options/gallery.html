Pet Sitter Finder — design options

Three structurally distinct home / search architectures for the marketplace. Each option is a different layout system, not a recolor of the same skeleton. Open a full option file for light + dark at 375px side by side.

Chosen direction is recorded in DECISION.md in this folder. Brand mark (logo PNG) is owned separately; expected ship path public/brand-mark.png (see design-refs/BRAND-NOTE.md).
Option A

Card grid marketplace

Sticky top search owns the job; results are a single-column photo+body card grid.

  • Primary surface: full-width result cards
  • Search: sticky slab under nav with chip filters
  • Not present: map canvas, calendar hero

Option B

Map-first + list rail

Map fills the working canvas; sitters are pins; results sit in a bottom sheet rail.

  • Primary surface: map stage with pins
  • Search: compact bar over the map
  • Secondary: bottom list rail sorted by distance

Option C

Timeline / calendar hero

Availability calendar is the hero; sitter list is secondary timeline rows with week bars.

  • Primary surface: date range + half-month calendar
  • Search: under the calendar, after dates are set
  • Secondary: timeline rows (not photo cards, not map)
