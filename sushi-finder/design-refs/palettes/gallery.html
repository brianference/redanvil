Sushi Finder — five palette directions

Colour is its own choice axis, but a direction is not a hex swap. Each column is a complete direction: tokens + type + component treatment (card shape, image ratio, chip style, type scale, density) on the same restaurant screen — in light and dark. Same real food photos across columns so the comparison stays honest. WCAG AA measured with axe-core on every direction (both themes). Choice is OPEN.
