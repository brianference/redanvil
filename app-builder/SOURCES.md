# Sources — app-builder

Retrieval / verification date: **2026-09-24**.

app-builder turns a plain-English app idea into a PRD for coding agents and can
queue a build job. It calls no third-party API at request time: the PRD is
generated by deterministic TypeScript in `src/lib/prd/`, and the only backend is
this app's own Pages Functions over its own D1 database. Everything a visitor
sees comes from one of the sources below.

## Data the app ships or stores

| source | what it provides | where it lives | provenance |
| --- | --- | --- | --- |
| The visitor's own answers | Prompt, app type, auth choice, entities, features | Sent to `/api/submit` and `/api/prds`, stored in D1 `jobs` and `prds` | Typed by the visitor; validated with Zod at the boundary |
| Seeded PRD `prd-tesla-driving-stats` | The one row that lets `/api/prd/[id]` show a success path on a fresh database | `migrations/0002_seed_prd.sql` | Copied verbatim from `src/lib/prd.characterization.fixtures/dashboard-auth-two-entities.json`, a recorded output of this app's own generator (stated in the migration header) |
| Shipped examples on /examples | Prompt, PRD and screenshots of apps that were built and deployed | `src/lib/examples.ts`, images under `public/examples/` | Frames captured from production by `.github/scripts/capture_example.mjs`; code claims pinned to commit `f48afd7d1384` of the RedAnvil repository |
| Stack references in each PRD | Documentation links for the stack the PRD names | `src/lib/prd/stackReferences.ts` | Official docs: developers.cloudflare.com (Pages, Pages Functions, D1), zod.dev, developer.mozilla.org (Web Crypto), vite.dev, react.dev, playwright.dev |

## Design references (R23)

`appstore_refs.mjs` was run on 2026-09-24 with the terms `prd`, `product
requirements`, `app builder ai` and `spec writer` against the public iTunes
Search API. The result is recorded here honestly: the App Store has almost no
PRD tools. `product requirements` returned nothing, and `prd` matched unrelated
fitness and shopping apps (WeightWatchers, Simple, FitCoach, Argus, Pinduoduo)
that are not references for this product.

category's real competitors are web products and in-repo tools, so the product
comparison lives in `COMPETITORS.md` and the build-versus-integrate record in
`INTEGRATIONS.md`.

## What is not a source

- No LLM or other hosted generator is called to write a PRD. A changed PRD is a
  changed template, caught by the characterization tests.
- No invented example apps. An entry on /examples exists only after its frames
  were captured from a real deployment.
- No analytics or third-party tracking endpoint.
